## 📖 About

This is an **Exploratory Data Analysis (EDA)** project built with Python. The notebook explores the famous **Titanic dataset** to uncover insights about passengers, survival rates, and the relationships between different features.

Every visualization is paired with **clear, recruiter-friendly observations** — so it's not just "here's a chart," it's "here's what the chart tells us."

---

## 🚀 Features

- 🧹 **Cleaned and explored** the Titanic dataset end-to-end
- 📊 **Visualized distributions and relationships** using Matplotlib, Seaborn, and Plotly
- 📈 **Applied statistical techniques** — correlation analysis and outlier detection
- 💡 **Recruiter-friendly observations** for each visualization
- 📝 **Notebook structured with Markdown explanations** for clarity and storytelling
